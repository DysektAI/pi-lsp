# Roadmap

The initial release includes managed installs, menu-first management, doctor and uninstall flows, warm diagnostics/navigation/symbol tools, pagination, edit feedback, and safe rename/code-action previews.

## Candidate next work

- Explicit persisted trust for project-local language-server binaries
- Optional application of rename/code-action previews through a transactional mutation layer
- Java support with a maintainable, verified cross-platform JDTLS distribution strategy
- Diagnostic pull-capability negotiation for servers beyond C#
- Configurable server settings without executable overrides
- Completion and formatting tools if agent workflows demonstrate value

## Evidence-gated

- Tree-sitter fallback
- Shared cross-session daemons
- Broad catalog expansion without reliable managed installers

These features increase lifecycle, security, or correctness scope and should not be added solely for parity.
