# Changelog

## 0.1.0 — 2026-07-23

- Added menu-first `/lsp` manager with status, doctor, install/update, stop, safe uninstall, and install-all-applicable actions.
- Added isolated npm, Go, and .NET server installs plus rustup integration.
- Added first-class Windows command/shim handling and optional official Go bootstrap through winget.
- Added TypeScript/JavaScript, Python, Rust, Go, C#/.NET, JSON/JSONC, and YAML routing.
- Added diagnostics, hover, definitions, references, document/workspace symbols, pagination, rename previews, and code-action previews.
- Added warm process pooling, read warmup, post-edit diagnostics, process recovery, solution-aware C# roots, and ownership boundaries.
- Added cross-platform CI, regression tests, security guidance, architecture, catalog, upstream comparison, and attribution tracking.
